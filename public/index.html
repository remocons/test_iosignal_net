IOSIGNAL / OPEN WORKBENCH ·

전환 시 연결이 종료됩니다. 브라우저 정책에 따라 HTTP 요청이 다시 HTTPS로 열릴 수 있습니다. 인증키는 전달하지 않습니다.

HTTP로 이동을 요청했지만 HTTPS로 열렸습니다.

브라우저의 HTTPS 자동 전환·HSTS 정책 또는 서버 리다이렉트가 원인일 수 있습니다. 웹앱에서 강제로 HTTP 접속을 허용할 수는 없습니다.

주소창에 HTTP 주소를 직접 입력해 확인하세요. 그래도 HTTPS로 열리면 WSS 서버 또는 로컬에서 실행한 웹앱을 사용하세요.

연결하고, 보내고, 확인하세요.

Arduino · 웹 · Node.js를 위한 범용 통신 실습실

실습 안내 ↗

01 연결

인증 접속 (선택)현재 연결에만 사용합니다. 프리셋·로그에 저장하지 않습니다.

미연결 · 내 CID —

공개 서버는 HTTPS + WSS를 권장합니다. localhost는 현재 브라우저를 실행하는 기기이며, LAN의 다른 서버는 해당 IP를 입력하세요.

02 실습 선택

보드별 튜토리얼 ↗

프리셋을 바꾸면 권장 태그와 구독 목록을 채웁니다. 이전 구독은 해제합니다.

03 송신

‘여러 인자’의 []는 EMPTY, [null]은 null 하나입니다. 바이너리는 HEX 입력을 사용하세요.

04 구독

직접 시그널은 구독 없이 수신합니다. 재접속하면 이 목록을 다시 구독합니다.

05 통신 로그

최근 200건 · TX는 송신 호출 기록이며 장치 실행 완료를 뜻하지 않습니다. 전구 대신 실제 수신값을 확인하세요.
